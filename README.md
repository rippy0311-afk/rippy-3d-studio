# Rippy 3D Studio

100種類のOBJを選んで組み立てる、ブラウザ用3Dエディター。

公開URL: https://rippy0311-afk.github.io/rippy-3d-studio/

- 100種類の形を配置・複製・削除
- X/Y/Z方向のサイズ・位置・角度を変更
- 慣性なしのカメラ操作
- OBJファイルのダウンロード・書き出し

編集内容はメモリ上に保持され、再読み込みするとリセットされます。OBJ書き出しには色は含まれません。

GitHub Pages: mainブランチのルートから配信。
